# AI Pivot Asset Backlog

This file captures the first asset slate created by the book's repositioning toward an AI-era operating methodology.

These are not final graphics yet. They are concept assets that should later become registered assets in `book/config/assets.json` and be placed into chapters with visual placeholders.

## Asset 1: Old Bottleneck vs New Bottleneck

- **Asset id suggestion:** `bottleneck-shift-map`
- **Type:** concept-diagram
- **Purpose:** show the shift from code-production bottlenecks to context coordination, governance, integration, and decision quality
- **Likely chapters:** introduction, Chapter 5, Chapter 10, Chapter 11
- **Notes:** this is probably the most important visual in the new version of the book

## Asset 2: Framework Map

- **Asset id suggestion:** `framework-map-ai-era`

## Working Rules

- A visual earns its place by clarifying a concept first.
- These assets should support the new spine of the book, not decorate it.
- We should prefer visuals that help the reader understand the bottleneck shift, role shift, and method synthesis.
- Before any asset becomes final, we need:
  - caption
  - credit/reference if needed
  - chapter placement
  - reader-facing purpose
