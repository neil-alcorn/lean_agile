# Traditional Publishing Workspace

This folder is the working area for the traditional publishing path for *Lean and Agile*.

The goal is not to rush submissions. The goal is to build a professional, well-researched package that can be used to approach agents and selected publishers when the book and proposal are ready.

## Files

- `TRADITIONAL-PUBLISHING-STRATEGY.md`
  - overall approach, what to do, what to avoid, and where this book likely fits
- `PROPOSAL-BUILDOUT.md`
  - the proposal structure we will build toward
- `TARGETS-AND-CONTACTS.md`
  - current draft list of target agencies and publishers, with public submission routes and notes
- `PITCH-DRAFTS.md`
  - working elevator pitches, query hooks, and early positioning language

## Working Rules

- Do not submit anything until the package is intentionally ready.
- Re-validate each target's submission requirements before outreach.
- Prefer agented submission for major trade publishers.
- Do not pay agents or publishers up front.
- Track every contact, requirement, and revision in this folder so the outreach process stays coherent.

## Current Position

As of April 20, 2026, the best path for this book appears to be:

1. build a strong nonfiction proposal
2. tighten platform and market positioning
3. identify agents with business/nonfiction fit
4. selectively approach direct-submission publishers that fit the book
5. keep revising the manuscript and proposal in parallel
